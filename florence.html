8  Florence eBinders

8.1 1. Registration & Navigation

8.2 Training Links

  • https://university.florencehc.com/
    • self-register for the Study Staff training
  • Training Environment

8.3 Navigation

Sidebar items all have their own training modules * Binder link on sidebar - back to homepage

  • When you sign in you will be taken to the binders page which is like the homepage. You’ll see any binders you have access to.
  • Search bar lets you search for documents or placeholder. Click blue box to see list of results. Click to go to that item
  • Use filter box to reduce the results on any page.
  • Breadcrumb link may be truncated to save space, click the folder icon for the dropdown to expand
  • Top right is settings and user profile dropdown.
  • The florence logo upper left will take you back to the teams page if you have multiple teams.

8.3.1 Profile

  • Edit profile (includes password change)
  • Edit Email notifications on the your-name dropdown - the option can be used to set up frequency and time

8.4 Global View

  • See summary of binder or folder
  • See placeholders left in study startup
  • Select the checkbox near the binder or folder and select Global View under the dropdown.
    • OR select GlobalView in the left-hand sidebar
  • Use the + to see what’s inside it or click the + by a location to open every folder and subfolder. Clickable colored boxes can filter the view. Click again to undo the filter. (You can still use the filter View box but it will only look for binder and document names and not placeholders

8.5 Need help

  • Sidebar or under your name
  • Contact for our team
  • Or go to the helpdesk which is their KB. You can also chat

8.6 2. Documents & Signatures

8.7 Uploading a document

  1. Use global view to get to the place the document needs to live.
  2. Once you’re in the folder you’ll see a box in the lefthand sidebar. Drag here or select browse to find on your computer.
  3. Docs live alphabetically
  4. If you see “Preview not available” florence recommends converting to a regular PDF to permit the preview.

8.8 emailing docs into florence

  • navigate to the correct location
  • Sidebar - “Import via email” box
    • Copy that email address
  • forward an email to that address, or BCC the florence address (in case someone might reply all)
    • If you reply, you need to re-attach attachments
    • Subject of email will be title of florence doc
  • Everything is converted to PDF

8.9 Annotations & redactions

  • 4 buttons at top of document view: View, Annotate, Redact, Sign
  • Annotations create new versions. You’ll need to confirm
    • Highlight works if the document hasn’t been flattened
    • Rectangle works for flat documents. It creates a rectangle around an area of attention.
      • You can propagate a rectangle to all pages by the Propagate button (looks like copy icon)
    • Free text, click anywhere and type. Color, background, font, style
    • Strikeout allows UNFLATTENED docs to be struck out.
    • Timestamp - select and click anywhere to get it to show up.
  • Redaction: protect PHI/PII
    • Only those with “View PHI” permission can see the un-redacted version
    • Can also use propagate here
  • BE SURE TO CLICK SAVE. If you navigate away all changes are lost.

8.10 Downloads

  • Any doc can be downloaded if you have permission. From folder view, select Download from actions dropdown in the folder, or from the Manage dropdown in document view.
  • You can select to include signature addendums, and whether you wish to get all versions or just the current version.
  • My Downloads shows all your downloads (left sidebar)

8.11 Moving documents (or placeholder or folder)

  • Select and navigate to Actions -> Move
  • Only like items can be moved at the same time.
  • You’ll see a tree with the current location in blue. Once it moves you’ll see a link in the new location.

8.12 Uploading a new version

  • Navigate to where the document lives and select the Version dropdown
  • Drag & drop or browse, or select Email to import that way.
  • Provide the reason aka “expired, updated” etc and change names as needed
  • Can also clear expiration dates and rename shortcuts

8.13 Duplicating docs, folders, or placeholders

  • Select the item(s) and go to Duplicate in actions dropdown. (must have permission)
  • Tree shown with destinations (blue is current location)
  • If you only select 1 item you can include versions and rename (handy if say you duplicate a set of docs for all sub investigators)

8.14 Signing a document

  • You van get an email notification of a signature requests.
  • GO to notifications to turn these emails on
  • Blue bar at top of screen lets you know you have signatures needed
  • Viewing your queue goes to reports section; click any doc to go there

Signature types:
* Addendum * Stamp

(Discussed later)
* Form * eLog

Addendum:
* Clicking “Sign” pops up the signing modum. * Adds a page to the end of doc with the signature. * Left hand panel shows last update

Stamp: Physically stamps. * You click & drag to put it where you want it. * Creates a new e-version of the doc

If you attempt to sign an expired document, the “Sign” button won’t be available. Check the date in the audit trail. Contact the person who requested your signature and have them update the date.

You can also decline to sign, if either it doesnt require, or if the doc is inaccurate, or if the sig type requested is wrong.

  • Select decline and enter your reason. This goes in audit trail and emails requestor
  • If it’s just because the signature type requested is wrong, you first decline and then can go back and sign with any signature.

8.15 Requesting a signature

  • Can request from folder View by selecting the checkbox then actions dropdown -> request signatures
  • You can select other documents from the next modal from anywhere in your structure.
  • Then select signature type and reason why for each document.
    • If some needs to sign approval and others to acknowledge, you should send those separately to each group.
  • Go to signers tab and start selecting users. THere is NO option to select all.
  • If someone has permission they will get a request. Only select users who can sign all docs.
  • YOu can add a sign-by date and whether you want to be notified of signatures, and if you want to email them the request. They only get one notification per request, not a separate email for each doc. *Pending tab shows if some are already in progress. If someone is here, they won’t show up in the Signers tab.
  • Gold arrow by name or doc means a signature is in progress.
  • Lock shows who don’t have access to certain documents. They wont get the request for those docs.

8.16 Sending a signature reminder

  • Navigate to document, from Manage tab select request signatures, and look at Pending tab. YOu can select to send a reminder.
  • Or navigate to report section and select Signatures Pending. Click any and click Send reminder to send.

8.17 Cancel a signature request

  • Navigate to the document and select Request Signatures from Manage dropdown.
  • Go into Pending tab and select which people to cancel. Under Actions click cancel

8.18 3. Shortcuts, due dates, placeholders

8.19 Shortcuts

  • Helps you maintain docs in one central folder but access from anywhere.
  • Create a shortcut in the “to” document > Create a new shortcut tto it elsewhere
    • Select document in folder and under Actions > Create shortcut.
    • This brings up the tree for where you want to PUT the shortcut.
  • Or Import - start with the new location where it should live, and > Import a new shortcut to it.
    • Navigate to the location where the shortcut should live. Create New > Import Shortcut. You;ll be taken to the tree, and can select the items.
    • All have “shortcut” after the document title.
    • In shortcut view, you can see a link in the sidebar to the original site.
    If you delete a doc you should also delete the shortcut

8.20 Due dates

  • Keep track of placeholders that need to be filled.
  • Set a due date, open placehodler, and cliock Set Due Date in left sidebar. You can subscribe to notifications under your name for “Documents due in…”
  • Global view shows upcoming dates or overdue date
  • You can run reports for placeholders

8.21 Expiration dates

  • When uploading a doc set an expiration date to remind users when it needs to be updated “Set expiration date” in sidebar.
  • Subscribe to Notifications under your name. It will also be in orange or red in the global view
  • Also available in reports section

8.22 Bulk due dates and expiration dates

  • These can be uploaded in bulk from the folder level. Add due dates/expiration dates for all in folder by adding everything.
  • Under Actions click “Update expirations/due dates”
  • Select bulk assign in top right, select all, then set the date in the first view.
  • There’s a calendar view or quick options.
  • When Bulk assign is toggled off, you can set individual dates
  • Can only do this on a folder by folder basis.

8.23 Placeholders

  • Keeps track of expected documents
  • Can create in standard folder in excel for easy uploading, and use due dates
  • Or individually, navigate to the desired location and clic Create New > Placeholder

8.24 Filling a placeholder

  • Navigate to the placeholder either by global view or click through to where it lives
  • Drag and drop or browse for the document
  • It will take on placeholder name after upload
  • Lefthand placeholder has original name
  • You can also fill with an existing doc in Florence or email it in.
    • Open placeholder and open Version dropdown to select Email (attachment will replace placeholder and email is created as a new file)
    • Fill with ebinder doc:
    • Move, duplicate, or shortcut.
    • Find in tree (blue is where your placeholder is you’re filling)
    • Add name

8.25 4. eLogs & forms

8.26 Using elogs

When it’s time to start filling out your e-log, click Add Entries

  • You can start populating info row by row - staff, role, start and end date
  • Use the commments section to indicated what changes are being made to store in the audit trail
  • Add as many rows as needed.
  • Make edits with Actions dropdown. Audit trail, edit, sign, or request signatures
  • Any change made to ENTIRE log is under the Manage tab dropdown.
  • note that changing a row, makes a new version ON THAT ROW (not to all the versions)
  • Signatures previously gatehred to not show on the new version.
  • After saving changes, enter the reason for these chnages (might be same as notes)
  • To see prevous versions use the v at the far right of the row

## Signing

  • You’ll be notified of signatures needed by you
  • scroll for the log and look for the yellow signature field that says “sign here”. Ignore all other fields
  • Toggle on actions dropdown “my pending signatures” hides rows not requiring your signatures.
  • YOu can sign individually, or checkbox all and go to Actions > Sign.

## Requesting signatures

  • Select the row and choose Request signatures under the Actions dropdown.
  • If the ENTIRE log needs signing - ie the PI signs off on an entire log at the end of the study - use the manage dropdown > request signatures. This sig goes to the WHOLE log
  • When you open the request sig modal, team members will prepopulate, but you can also select in the user search box.
  • If someone needs to sign twice, you have to request the first signature, have them sign, then request the second signature.
  • Select what column to sign, and reason.
  • Remember if you add a sign by date and they don’t meet it, you’ll need to go into Pending and change the date (you can also send reminders here)
  • You can request notification of completed signatures and to notify the signers.
  • Back in the row view - “Sign unrequested” means you havent requested any sigs for that row. “Pending other user” means a signature HAS been requested.
    • Any user can sign in a “sign unrequested area” if they choose, but best practice is always to request

8.27 Bulk signature reuqests

  • Can be sent in bulk.
  • First, log template needs to be updated to include the “Team members” row.
  • Select the rows and use Actions |> Request signatures
    • A dropdownn lets you specify for any given column: do you need multiple signatures from multiple signers, or multiple signatures for same signer
    • For multiple signers, they’ll be populated use the bulk assign or assign reasons individually. You can click the row number to doublecheck the info. It’s not clear how each row gets assigned - in her example
    • For a single person with multiple signers you get prompted immediately to select the signer. (like the PI needs to sign off on multiple rows)

## Bulk upload of rows in eLog

  • You can add multople team mmebers to say the DOA log this way.
  • Go to Manage > Import Rows
    • Download excel template, view tutoarial
    • DD/MM/YYYY for date formats but excel defaults to 2 digit Y. So you have to highlight entire doc and change to “text” so excel doesnt change it
  • You’ll get an error message once any errors are corrected/
  • Florence only ADDS NEW ROWS. You cannot import missing data to existing rows - this has to be done row by row

8.28 Fillable forms

  • Created in adobe and uploaded in documents (ie 1572, fin disclosures)
  • You can create multiple signature fields but florence only allows one signer per document. So if you need muttiple signatures it’s better to use elogs.
  • Can’t create contiuation pages - these must be created and uploaded from outside
  • NO dropdowns, just check box and radio
  • You can create required fields which FLorence highlights as red
  • Options are save as draft, or finalize.
  • Confirm you are ready to flatten the document (remove the fillable fields) and it becomes a flat pdf. After this you can use annotation to change (creates new version and may require a new signatuer)

8.29 Signing fillable form

  • the sign button is greyed out, click once in yellow signature field once and then click save to sign.

8.30 5. Structure

8.31 Creating binders

  • Log in go to Binders page and you should see “Create binder” just above the list of binders. If not you dont have create permissions
  • Name the binder according to naming convention and add labels and assign then click create. Appears in alpha order with other binders

8.32 Creating folders

  • Navigate to where you want it to live
  • Click into Create New and select Folder. Add lables, click assign, click create. Number prefexes can help order them

8.33 Importing folder structure

  • You can upload an excel structure file which creates folders, subfolders, labels, due/expiration dates, and placeholders.
  • Team admin may have already created these and stored in UAT environment
  • Once you have created the structure, click the checkbox where you want it to live, go to Actions, and select Apply Structure.
  • 2 options: Single use to copy a structure from Excel, or Reusable Structure from Template, which is created in your team.
  • So for excel, Navigate to the folder (aka root of binder) and click Action > Add structure > Single use. Modal shows a structure for creating the excel file from scratch. YOu can copy from your excel and paste into the modal box to copy your entire structure.
    • Click preview to see what it looks like.
    • Red indicates a formatting issue, it says what line the error is on and how to fix.
  • Click save. It takes a minute.

8.34 6. Access Management

8.35 Team Members

  • IF you have permission to invite users to team
  • Under Settings in top right >> Team Members. You see every person invited to your team and their email and role. You may see a warning that they have no roles.
  • Add members at top. Enter their email address (separate by comma). Check to send an email invite.
  • If you use SSO DO NOT CHECK THAT!!!
  • Give them a role on the checkbox to the left of their name, actions dropdown > Manage Access, type in name of existing role. MAKE SURE TO TURN THE ROLE ON with the toggle and set start/end date
  • Top of page: report dropdown to view reports on all users, role given, whether access will expire. Can download to CSV or filter. Also gives audit trail of who invited who

8.36 Permissions overview

  • It’s how you find out what permissions were granted to a specific user OR role.
  • Settings > Permssions Overview
  • Select user or role (Like in dionysus) - shows all binders/folders they can acccess OR not access.
    • Use plus by each item to see nested items
    • Hit edit to change role/user perms

8.37 Create a role

  • You can edit pre-created roles if you have permission with limited scope
  • Settings > Roles shwos all created. Top left is Create Role
  • Name the role (very specific!)
  • Then select that new role from the list and click Role Permissions to give it permissions
    • Create New > then select either Team level, Binder level, or Folder level permissions.
    • Work on each location permission separately.
    • Next takes you to the permissions tree where you can select any permission.
    • You may also need to add View Permissions to navigate there, it will remind you.
    • Edit menu gives you remove or update permisison options
  • Finally add users to that role.

8.38 Duplicate a role

  • If you need a very similar role but not exact permissions, you can duplicate.
  • Settings > Roles
  • Check the role and on the meatball menu select Duplicate. Give it a new, specific name.
  • Open meatball menu by new role. You need to make ABSOLUTELY SURE you get it right.
  • Click meatball by old role and a tree appears, UNCHECK the old location and selec the NEW location. As long as the permissions can be exactly the same, you can click save, or edit the permissions here.
    • Repeat for all old locations

8.39 7. Admin Tasks (team setup, etc)

8.40 Announcements

  • Announce new folder structure with link to the new folders

  • Left sidebar “Announcements”

  • Send Announcement, Your inbox, and Team inbox.

  • Enter a title and add message content, then select one or more binders, folders, documents

  • Next screen you can select by user or role (they must have team inbox permission turned on)

  • An email is sent and it’s in Announcements.

  • Think about creating Announcement specific roles

8.41 Team notifications

  • You can control email notifications for your whole team
  • Settings > Team notifications (you can search by user)

8.42 eLog templates

  • Navigate to Settings > Log Templates
  • Create OR update here so you can create any master then send to applicable studies
  • Some will already be created for you and you can use the meatball menu to edit, OR create new.
  • In Creating, make sure the details here are generic so they can be applied to any study.
  • Add detail to include more information
  • Create a legend just like for paper logs.
  • Provide info on General Info
  • Build out log columns. Enter title then change type (text, Team Member, Date, Signature). They cannot be changed after sent to a study so make sure they’re right.
  • Use Version comments if you’re changing an existing log (for audit trail)

8.43 eLogs - Adding to study

  • When ready to add a template eLog to study, navigate to where log should live.
  • Create New |> Log. Give it a name and then select the template.
  • You’ll be asked to enter the log details specific to this study’s log. (You can edit this later)
  • Log details appear in left sidebar, legend and instructions appear at top. Below that is where you start adding entries.

8.44 Structure templates

  • Settings > Structure Templates
  • Here you can see list of imported templates (with right perms)
  • Top of page: Audit Trail and Assign Structure
  • meatball on a template lets you see the audit trail or preview

To add a new template:

  • Click Import excel structure templates
  • Browse to excel. Errors are flagged. Click next when fixed
  • Name template and add description.

8.45 Assigning a structure to a binder or folder

  • TO use a template, either “Assign Structure” at template page, or Actions > Apply Structure at the binder or folder level.
  • From template page you can select either a binder or folder structure.
    • Create new OR add to existing binder.
    • For folder level, you first select the binder you use. Either Create a new folder in the binder or Assign to existing folder.
  • From binder page, Actions > Apply Structure > Reusable template chooses from the templates in Florence. Select the model.
    • The binder or folder needs to exist BEFORE you Apply the structure.
    • You can also apply expiration dates (documents) and due dates (placeholders). Apply one by one, or click the folder icon itself and all placeholders get selected.

8.46 Audit trails

  • On Document, Folder, Binder, Role, and Users
  • On any object or Roles, check the box next to the item and click Actions > Audit trail and use filters to drill down. You can also download
  • On documents, left sidebar near bottom has the audit trail button
  • For team member audits only, go to Settings |> TeamMembers to look at these audits. Audits are under the Reports dropdown. These only show role and permission changes not like every action they have taken in Florence

8.47 Document locking

  • This allows you to disable certain actions (limits it to View and download only)
  • Select one or more documents, then Actions > Lock Document (reverse, Actions > Unlock). They’ll have a lock-doc icon. If you open the document you’ll see it’s locked by a red message and a watermark (removed when unlocked)
  • Locking a document will prevent the doc from being signed or tasks being completed. The request and task will still show as open but the user can’t make any updates. So be sure there are none pending!!
  • This is useful near end of study - ie locking shortcuts no longer receives updates from the original document.
  • Also template docs that can be duplicated but not edited or moved itself.

8.48 8. Reporting tools (tags, labels, tasks)

8.49 Reports

  • In left sidebar select available reports
  • Some don’t work yet, but it’s random rare ones.
  • After selecting report choose folder or folders (but only ONE binder ) or select all for team level
  • You can filter or download
  • Task/signature reports allow you to send reminders right from the report location

8.50 Labels

  • Assign attributes like PIs, study IDs, etc. (Like current paper coversheet)
  • Labels are under Settings > Teams.
  • On top of report are Florence-level labels. It must have a value to be assigned.
  • Create to give it a Label, Description, and values (like, list all PIs or list all Sites)
  • Changes are captured in the audit trail.
  • Select the item you want to apply a label to. Meatball > Rename/Update. First you select the label name, then the value of the label to include.
  • On binder level, a label goes to ALL folders and docs under it. On folder level, all sub folders and docs.
  • Label reports: select label, value, and binder or folder,

8.51 Tags

  • Tags are just like social. IE, you can tag all docs in any location (ie “IRB”).
  • YOu can also tag placeholders.
  • Create list of tags in Settings > Tags
  • Make sure you dont duplicate an existing tag!
  • Open the item you want to tag, select Manage > Assign tags
  • Appear at bottom of left document sidebar

8.52 Creating a task

  • Like a todo list
  • Can track progress and check pending
  • Go to the item and hit Manage > Create Task
  • Add a task title and message for the assignee. Set notification preferences, Assign with the filter for users.
  • When they complete the task they can change the status to Complete and assign back to you before marking it as close to end the task

8.53 Completing a task

  • On the binder page a Green bar at the top takes you to pending tasks
  • Or, you can check your notification emails and click through from there to go directly to the task
  • Or, in reports, select Tasks - My Queue
  • In global view they are in a colored box above tree
  • Status can be To Do, In Progress, Complete, and Close
  • When you finish your part set status as complete and assign back to creator.

8.54 9. MRM & Study profile management

8.55 Study Profiles

  • Track your study and get advanced reporting
  • Add this workflow immediately after importing folder structure. Go to Settings > Team Settings. Top tabs includes Study Profiles
  • Create Study near the top: Enter all required information and at least one study. Click “Save and connect study”
  • On the next page click “Connect binders and folders” button and select the new binder matching the study.
  • You can also apply it to your site
  • Reports > Study profiles Reports and select your study profile. You will download as csv to see all advanced reporting in one place

8.56 Remote Monitoring in Florence

  • Tag documents you think are ready for monitor review and assign those to the monitors with Create Task
  • At the document level there is a Monitor Review module allowing monitors to Approve or Create Query for documents inside the study you’ve given them access to.
  • Both options allow remote monitoring
  • It may not be enabled for our team

8.57 Using the monitor review module as Study Team

  • To allow this use, we need to make sure it’s been turned on for our team (lol)
  • Add the protocol ID label to the study which needs monitoring.
  • Make sure monitor and staff have role/permission access to both the study and to use the monitor review module.
  • Monitor will create queries for documents that need further action or Approve if ready for trial master file
  • A query can send notifiations to study team members. OR, go to Reports |> Monitor Reviews Open Queries > Select study
  • You can click each item that has an open query to be taken to that document.
  • Queries section is bottom left sidebar. Open to see what the monitor found. Take the requested action and then respond through the modal. They can review and mark document as approved
  • You can also see open queries and approvals at the folder level by looking at the icons.
  • Or in goblal view there’s a box for Approved & for Open query

8.59 ePrinter PHI Flag

  • when using the eprinter, you can flag PII/PHI containing documents at import.
  • In your print dialogue, check PII/PHI docs and hit Actions > Mark as PHI. They get an icon with a person and a lock.

  • The result is only people with PHI access permissions can see the document if it’s flagged this way
